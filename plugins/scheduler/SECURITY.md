# Security policy

This plugin follows the security policy of the dortort/claude-plugins marketplace:
supported versions and the private reporting route are in
[SECURITY.md](https://github.com/dortort/claude-plugins/blob/main/SECURITY.md).

Report vulnerabilities privately through
[a GitHub security advisory](https://github.com/dortort/claude-plugins/security/advisories/new),
never in a public issue or pull request.
